# Celestial-Gesture-HCI
A real-time, gesture-controlled 3D Solar System Orrery utilizing computer vision (MediaPipe Hands) and WebGL (Three.js) for touchless spatial interaction.
# Technical Depth: It explains the Exponential Moving Average (EMA) algorithm (α=0.06) used to filter out raw camera noise and prevent tracking jitter, and the Keplerian orbit interpolation math used to slide the planets between their orbits and the sun during your hand gestures.
# The Testing Sandbox (heart-test.html): It showcases your parametric heart test (3,000 particles mapped using Cartesian heart equations) as a proof-of-concept benchmark used to calibrate fingertips, palm spread, and wrist rotation vectors before scaling to the 60,000-particle system.
#Real-World Applications: It outlines the concrete, industry-level problems your project solves:
     1. terile Medical Interfaces: Touchless navigation of 3D MRI scans in surgery.
     2. Interactive EdTech: Kinesthetic learning of astrophysics and orbital mechanics.
     3. Industrial / Heavy Duty Fields: Dirty-hand interaction with interface panels.
     4. Museum Installations: Durable public touchless interactive exhibits.
# Tech Stack: (WebGL, Three.js, MediaPipe, Web Audio API, JavaScript ES6)
